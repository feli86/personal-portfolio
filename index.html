Featured Projects

A selection of academic projects and work I have developed and contributed to.

Mobile Application Development

Sarawak Lingo

An educational mobile application designed to enhannce young Sarawakian children's readiness for elementary school through an engaging and culturally relevant Malay language learning experience.

Developed as part of a six-member team, the application features interactive lessons, quizzes and gamified exercises to make language learing enjoyable while encouraging children to appreciate and preserve their cultural heritage.

Mobile Application Educational Technology Gamification Glide

UI/UX Design & Prototyping

Kuching ART Mobile Application

A mobile application prototype designed to improve the user experience of the Autonomous Rapid Transit (ART) system in Kuching, Sarawak.

The design process involved interviewing different user personas, including tourists, working adults, non-working adults and senior citizens to understand their transportation needs, preferences and challenges.

Based on the findings, we designed different application features tailored to the needs of various user groups with a focus on accessibility, convenience and user experience.

UI/UX Design User Research Prototyping Figma

Game Development

Life Below Water

An educational game inspired by United Nations Sustainable Development Goal 14: Life Below Water, which promotes the conservation and sustainable use of oceans and marine resources.

The application integrates interactive learning materials, quizzes and a leaderboard to encourage players to learn about marine conservation through an engaging gaming experience.

GUI Development Game Development Animation Module Integration Visual Studio Code

2D Game

Marine Conservation 2D Game

A 2D game developed using computer graphics programming in Visual Studio Code, inspired by marine conservation and SDG 14: Life Below Water.

Players take on the role of a lifeguard or marine conservationist tasked with collecting falling turtle eggs from eroded coastal soil.

Computer Graphics 2D Game Development Game mechanics Visual Studio Code

Database Management

Online Auction Marketplace

A mobile application prototype designed to improve the user experience of the Autonomous Rapid Transit (ART) system in Kuching, Sarawak.

Developed a locally hosted web-based auction marketplace connected to a MySQL database. The system manages user accounts and auction listings, including item descriptions, categories, starting prices, reserve prices, Buy Now prices, auction schedules and listing statuses.
